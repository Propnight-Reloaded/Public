# Patch notes

Notes de version écrites pour les joueurs, une par version stable, tous composants confondus (launcher, mods, relay).
Elles sont rédigées et publiées depuis le panel (DiscordBot), qui écrit ici puis poste la note sur Discord.
Le launcher (popup de mise à jour, onglet News) et le site les lisent directement depuis ce dossier.

- `index.json` : liste des notes publiées, la plus récente d'abord.
- `<id>.json` : une note (titre, résumé court pour la popup, sections New / Fixed / Changes, image).
- `images/` : images des notes.

Le format est défini dans le ticket PN-1 (`PATCH_NOTES_SPEC.md` de l'espace de travail). Pas d'édition à la main
sauf correction : passer par le panel.
