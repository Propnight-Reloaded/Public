# Propnight Reloaded — dépôt public

Tout ce que le projet publie pour les joueurs et les clients, au même endroit :

| Dossier | Contenu | Lu par |
|---|---|---|
| [`bootstrap/`](bootstrap/) | `bootstrap.json` signé : adresses des services, validité, hôtes révoqués | le launcher, au démarrage |
| [`wiki/`](wiki/) | documentation joueurs, moddeurs et contributeurs | le site, le bot Discord |
| [`patchnotes/`](patchnotes/) | notes de version pour les joueurs | le launcher, le site |

Le dépôt est aussi servi par GitHub Pages (`https://propnight-reloaded.github.io/Public/`) et jsDelivr
(`https://cdn.jsdelivr.net/gh/Propnight-Reloaded/Public@main/`), miroirs indépendants du domaine du projet.

Les chemins de `bootstrap/` sont compilés dans le launcher : ne pas les déplacer.
